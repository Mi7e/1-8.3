# Портфолио 1С:Предприятие 8.3

В данном репозитории собраны мои практические работы по разработке на платформе 1С:

### 1. Собственная конфигурация (папка xmlбаза)
- Разработка велась в рамках практики на Волжском абразивном заводе.
- Исходный код выгружен в XML-файлы.
- Реализованы справочники, документы, регистры накопления и тд.

### 2. Внешние обработки и расширения (папка ВнешниеобработкиВодоканал)
- Задачи, реализованные во время практики в МУП «Водоканал».
- Включает обработки по обмену данными (JSON/XML), HTTP-соединения и работу с запросами.
